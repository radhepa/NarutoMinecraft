# Konoha plan

The whole Hidden Leaf planned as one city before more building. Spoiler-free.

| File | Holds |
|---|---|
| [MASTER_PLAN.md](MASTER_PLAN.md) | The frame (view axis, Rock, wall, river), districts, streets, landmarks and sightlines, terrain, density, story places and anchors, the quality bar |
| [DISTRICTS.md](DISTRICTS.md) | One sheet per district: bounds, built and planned plots with coordinates, people, anchors, batch |
| [TECHNIQUES.md](TECHNIQUES.md) | How to build: proportions at 1 block = 1 m, wall palettes and gradients, depth, roofs, fronts, light, streets, terrain, trees, interiors by home type |
| [BATCHES.md](BATCHES.md) | The ordered batch list (K3 to K14, then Beta 2 and 3) and every batch's checks |
| [RESEARCH.md](RESEARCH.md) | The research behind it: canon Konoha, Minecraft technique, Japanese interiors, with sources |
| [master_layout.json](master_layout.json), [master_plan.png](master_plan.png) | The draft layout (layout.json's format) and its plan view |

Scope and counts stay in [KONOHA_BUILD.md](../../KONOHA_BUILD.md); progress in
[docs/development/STATE.md](../development/STATE.md).
